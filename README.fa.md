# Cloner

یک برنامهٔ مک مستقل برای ساخت و مدیریت کپی‌های جداگانه از برنامه‌های `.app`.

## ساخت

به Xcode کامل نیاز ندارد؛ Swift 5.9+ و macOS SDK کافی است:

```sh
swift build --package-path . --configuration release
```

فایل اجرایی در `.build/release/Cloner` ساخته می‌شود. برای قرار دادن آن در یک app bundle، اسکریپت `scripts/build-app.sh` را اجرا کن.

## استفاده

1. روی «ساخت clone» بزن و یک برنامهٔ `.app` انتخاب کن.
2. برای clone نام بگذار.
3. برنامه در `~/Applications/Cloner/` کپی می‌شود، Bundle ID تازه می‌گیرد و با امضای ad-hoc امضا می‌شود.
4. از داخل Cloner آن را باز کن یا محلش را در Finder ببین. برای برنامه‌های مبتنی بر Electron/Chromium، پروفایل اجرای جداگانه ساخته می‌شود تا با نمونهٔ اصلی روی یک نشست قفل‌شده رقابت نکند.

فهرست cloneها در `~/Library/Application Support/Cloner/clones.json` نگهداری می‌شود. حذف از برنامه، فقط clone مدیریت‌شده را به زباله‌دان می‌برد.

## دامنه و محدودیت‌ها

- برنامهٔ اصلی فقط خوانده و کپی می‌شود؛ فایل‌های اصلی تغییر نمی‌کنند.
- Entitlementهای عمومی و قابل‌استفاده با امضای ad-hoc حفظ می‌شوند؛ entitlementهای وابسته به Team ID، App ID، Keychain group و App Group حذف می‌شوند تا macOS کپی را هنگام launch رد نکند.
- برنامه‌های Electron/Chromium از پوشهٔ پروفایل جداگانه‌ای در `~/Library/Application Support/Cloner/Profiles/` استفاده می‌کنند. داده و ورود حساب برنامهٔ اصلی به این پروفایل کپی نمی‌شود.
- امضای ad-hoc جای امضای Developer ID یا notarization را نمی‌گیرد. برنامه‌هایی که به entitlementهای محدود، receipt یا سرویس‌های اختصاصی وابسته‌اند ممکن است داخل clone اجرا نشوند یا بعضی قابلیت‌ها را از دست بدهند.
- جداسازی کامل Keychain/App Group و انتقال تنظیمات برنامهٔ اصلی پیاده‌سازی نشده است.
- این پروژه پیاده‌سازی مستقل بر پایهٔ رفتارهای مشاهده‌شده است؛ کد و دارایی‌های اختصاصی MacDupl در آن استفاده نشده‌اند.
